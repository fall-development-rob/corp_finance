# Process Letter

Draft a sell-side process letter using the Process Letter workflow from `workflow-investment-banking`.

## What It Does
Authors a phase-2 process letter defining the rules of engagement for a competitive sale process: (1) timeline and milestones (NDA / CIM, indicative bids, management presentations, data room, final bids, exclusivity, signing), (2) data-room access procedures (permitted representatives, restrictions), (3) NDA and non-solicitation requirements, (4) bid submission format (EV and equity value, consideration form, financing evidence, conditions, timeline to close), (5) evaluation criteria (price, certainty, speed, strategic fit, employee treatment), (6) standard legal disclaimers (seller reserves right to modify, no obligation to sell), (7) indicative-offer requirements and exclusivity language.

## Agent
Routes to `cfa-private-markets-analyst` with `workflow-investment-banking` skill.

## Key Tools
None required (pure document workflow).

## Usage
Provide deal context: project codename, target sector, indicative timeline, phase being entered (phase-1 invitation vs phase-2 final-bid letter), required bid format, exclusivity preference, and any custom evaluation criteria. The agent will assemble a phase-appropriate letter.

## Output
Formal letter (markdown) with: header (project codename, recipient placeholder, date), timeline table with milestone dates, data-room access section, bid-format requirements, evaluation criteria, exclusivity terms, standard legal disclaimers, and sign-off block. Suitable for distribution to invited bidders.
